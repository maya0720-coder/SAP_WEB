1. 현재 버전 저장, 기획서 다운로드 제공
2. 홈 화면 재설계: SAP 모듈(FI/SD/MM/CO/PP/LE) 기준으로 화면이 바뀌고 하위 개발 프로그램으로 들어가는 구조
   - 발주서 = SD 하위, 단가 = MM, 배송현황 = LE
3. 기존 기획서·레이아웃 기록 백업
4. 개발 폴더에 대화 로그를 남겨 다음에 기억할 수 있게
5. AI가 만든 티가 안 나는 디자인. 디자인 스킬 frontend-design / ui-ux-pro-max / impeccable / taste-skill / web-design-guidelines / supanova + 트렌드 스킬 1개 추천해 레이아웃 비교 미리보기
6. 발주서: [매출정보]는 [품목·개선상품]의 시스템별 합계 → 품목을 먼저 입력하거나 한 화면에 표시
7. 요구사항에 대한 제안을 그림과 함께
8. (작업 중 추가) 홈을 MAIN DASHBOARD로 만들고 즐겨찾기 기능 추가

## 2026-11-16 (세션 1) — v0.3: 통합 기획서·보안 검토·프로토타입

### 사용자 요청 요지
- 대상 3종: 외부 영업사원(현장 발주서 등록), 결재자(발주서·판매가·매입가 승인), 배송기사·SCM(배송 현황·기사 위치, 신규 기획)
- 로그인: fs.golfzon.com Entra ID / 연동: SAP RFC ↔ 외부 BSG AWS EAI ↔ SAP Web Service / 권한: SU01 역할 + AGR_TCODES로 화면 제한
- 요구: 개발·서비스 기획서, 구성도, 보안팀 설득 자료, 순차 TO-DO, 로그인·화면 레이아웃 미리보기, 추가 검토 사항, 제안 기능
- 참고 SAP 화면: 가맹 발주서(신규), [MM] 단가 변경 승인

### 결과
- [산출물] 기획서 v0.3 → 백업 `backup/v0.3/`
- [산출물] 프로토타입 v0.3: https://claude.ai/artifact/4SSGvEDPv5yr2XPGJi6787
- [제안] 1차 = 발주서 등록 + 결재함, 2차 = 배송(위치정보법 법무 검토 후)
- [제안] 배송 위치는 이벤트 기반(출발·도착·완료 버튼 시 1회 수집) + 배송 순번 공유. 웹 상시 추적은 비권고(숨겨진 화면은 위치 업데이트 중단)
- [제안] 메뉴 노출은 AGR_TCODES, 최종 차단은 SAP RFC 안에서 S_TCODE·조직 권한 재검사
